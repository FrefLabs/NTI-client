## 📖 Explicación del trabajo

El proyecto **NeuroFref Trading Intelligence (N.T.I.)** constituye una herramienta interactiva diseñada para simular y comprender el mercado financiero. El sistema utiliza datos reales e históricos para recrear escenarios del mercado bursátil, permitiendo al usuario (accionista) analizar comportamientos de los activos, responder a desafíos y poner a prueba sus decisiones dentro de un entorno controlado. 

La plataforma cuenta con un entorno de simulación (juego) donde el usuario puede interactuar con distintos escenarios, seleccionar niveles de dificultad y recibir retroalimentación inmediata según sus respuestas. Además, integra un sistema avanzado de **Redes Neuronales** capaz de crear, entrenar y solicitar predicciones de modelos financieros basados en el comportamiento de las acciones.

## 🎯 Por qué se hizo

N.T.I. fue desarrollado con el objetivo principal de mejorar el aprendizaje financiero y fomentar el pensamiento crítico. Se busca ofrecer una experiencia educativa dinámica que acerque al usuario al funcionamiento real del mercado, permitiéndole practicar estrategias de inversión sin riesgo. 

De esta manera, la herramienta se posiciona como un recurso educativo moderno, accesible y flexible, orientado específicamente a fortalecer las habilidades analíticas y apoyar la formación en inversiones de una manera práctica e inteligente.

## 🛠️ Tecnologías usadas

El ecosistema del proyecto se basa en una arquitectura Cliente-Servidor y se apoya fuertemente en el consumo de datos externos y algoritmos de IA:

* **Redes Neuronales / Machine Learning:** Para la creación, entrenamiento y ejecución de modelos predictivos de mercado.
* **API FinnHub:** Utilizada para obtener información detallada sobre las empresas, valores de las acciones y noticias financieras diarias.
* **API YFinance (Yahoo Finance):** Implementada para extraer datos específicos y el historial de cotizaciones de las empresas.
* **API ExchangeRate:** Empleada para el formato, conversión y manejo de las distintas monedas en circulación.
